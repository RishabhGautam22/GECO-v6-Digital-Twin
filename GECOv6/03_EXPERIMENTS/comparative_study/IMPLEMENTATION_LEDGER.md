# Software study lane implementation ledger

Owner task: `/root/software_audit`, coordinated with `/root/science_audit` for production physiology/calibration and `/root/research` for primary equation verification. These tasks share a host and filesystem; no independent laboratories, OS isolation or independently verified model diversity are claimed. Exact provider/model execution identifiers were not exposed for this GECOv6 assignment.

New source lives in `02_IMPLEMENTATION/geco_v6_study/`. `preregister.py` generated the immutable design and parameter split before study outcomes. `plants.py` implements a separately sourced Hovorka compartment plant and wraps the production original-family plant. `engine.py` keeps requested authority, emission, local measurement, network report, evaluator input and evaluator glucose separate, and implements matched detector/recovery/stop conditions. `campaign.py` freezes transferred production calibration plus clean-synthetic detector thresholds and retains every attempted run and full trace. `summarize.py` performs paired parameter-unit inference, retaining adverse/null outcomes and invalidity. `audit_results.py` checks every complete trace; `plot_results.py` is an optional scientific-figure entry point.

The full detector is deliberately identified as a new study adapter. It uses the repaired production filter and causal forecast but does not reproduce the legacy protocol/kernel stack. The simple arm and full arm have identical available sensor streams, command caps, local cutoff and reset authority. Their detector statistics differ. Shared quality/local authority remains present in the sham arm. The oracle arm is separately labelled as privileged offline reference.

New ordinary tests are `02_IMPLEMENTATION/tests/test_v6_study.py`. The initial13-test attempt had one test-fixture failure: the chosen random noise happened to quantize to zero, so it did not exercise the intended nonzero measurement perturbation. That receipt is retained. An alternating observation-only perturbation now verifies zero command/zero plant input despite measurement noise. An additional test prevents missing physiology from corroborating a current mass score through stale evidence. The current14 tests pass; logs retain both successful stages. No study random distribution changed for the test repair.

The initial forecast interface wording was clarified in a before-outcomes amendment after the science task supplied the final production API. The selected categorical policy is a mode, never a numerical median. The production filter's innovation-valid flag gates anomaly input, and absent physiology cannot provide fresh corroboration. Fresh participants' continuous fields are pooled medians, an explicit model-transfer assumption subject to reported clean performance. No locked outcome was used to choose that policy.

Only new GECOv6 files are modified. The earlier GECOv5 release is immutable. No radio, wire manipulation, firmware work, external device action, clinical deployment or new security case is part of this study. All actuator/sensor conditions reuse specified numerical components of supplied offline abstractions. Additional benign legacy forecast/config integration is separately authorized by the coordinator and will be listed with its verification when completed.
