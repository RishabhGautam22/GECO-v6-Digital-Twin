# Bundled input and dependency boundaries

The release includes supplied HUPA-UCM and D1NAMO source archives and extracted CSV inputs under `02_IMPLEMENTATION/data/raw/`. No new participant data were collected. `PARTICIPANT_SOURCE_FILES.json` gives portable package-relative paths, sizes and SHA256 hashes for all 52 CSVs and two supplied archives. The participant-level source identity, exact fit/tune/test boundaries, eligibility and canonical-array hashes are in `03_EXPERIMENTS/filter_calibration/INPUT_ARRAY_MANIFEST.json`; all 34 records are retained in the frozen calibration, including exclusions/failure.

The raw ZIPs do not contain a README/license/citation file detectable by name in this supplied subset; external recorded metadata is therefore preserved explicitly rather than inventing an embedded license file. This document summarizes recorded provenance, not a new legal review or expanded permission. It does not claim rights for unacquired datasets cataloged in the prior review.

Source records use package-relative paths. Historical runtime executables and `provenance.source` absolute paths remain in immutable receipts as descriptions of the original host. They are not used as input locations by the restored experiment runners. Restoration copies the required inputs and exact sources to a new directory; do not edit those receipts merely to make historical paths resemble the new machine.
